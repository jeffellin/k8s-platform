# k8s-platform

Declarative addons for homelab clusters with Flux + Flux Operator + Kustomize (no kapp/ytt).

- `clusters.yaml` -- cluster -> apps + options (the one file you edit)
- `apps/<app>/` -- kustomize base (+ `meta.yaml`: dependsOn, secrets)
- `clusters/<name>/` -- generated by `hack/render.py` (ResourceSets) + SOPS secrets in `secrets/`
- `bootstrap/bootstrap.sh <cluster>` -- install Flux Operator, age key, FluxInstance

Add a cluster: list it + its apps in `clusters.yaml`, `hack/new-cluster.sh <name>` (keys + secret skeletons),
encrypt the secrets, `hack/render.py`, commit/push, `KUBECONFIG=... bootstrap/bootstrap.sh <name>`. See docs/secrets.md.
